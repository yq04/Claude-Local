界面只管理输入、状态和执行记录；本机权限交给原生层；网络页只在用户点击后检测固定 Claude 服务连通性，不提供资源购买、Skill 安装或外部导航。两入口复用 YAML 中英文文案，原始诊断保留到呈现时翻译；系统语言与界面语言独立。
browser.tsx: 默认浏览器状态与「一键设为默认浏览器」（触发系统确认）、指纹与代理配置、当前身份独占资料的缓存清理、跟随目标地区的真实观测核验与显式机器对齐；站点永久删除使用 Alert 警告并默认取消；复用 Cromma UI 和活动日志。
browser-model.ts: 有界浏览器身份摘要与同步状态；工具箱与起始页共享配置、目标地区、机器、出口服务目录、观测接收时间与默认浏览器契约，不接入原生权限；三平台设备/CPU/版本核验由共用函数保持一致，Windows 必须 Win32。
browser-start.tsx: 检测区上方紧凑黑色身份工牌、绑定状态与不匹配/未知/断连；真实观测与回报编排，主应用同款斜纹/点阵卡片，全宽紧凑 2/3/4 列与小状态区，黄底波纹/红底原因/绿底大对勾；重测清空旧结果，断连/未知/上报失败不通过；不接入 Tauri 权限。
browser-verification.ts: 纯核验模型，逐项实际/目标值与失败清单，沿用宿主配置时区/语言/平台规则；只有完整回传且所有实测匹配才通过。
browser-verification.test.ts: 跨平台虚构上下文验证三态、失败原因、连接/定位未知和目标时区改变，不访问网络。
browser-network.ts: 按宿主服务目录经浏览器当前路由检测出口，限流/故障切换服务，校验结果并保留失败原因。
browser-network.test.ts: 模拟限流、备用响应与非法出口，验证故障恢复和错误信息，不访问外网。
main.tsx: 自主 CL 品牌图与 Claude-Local 标志，默认身份页并记住上次安全页面；单窗口暖灰/橙色侧栏按 Laper VerticalNavbar 的 240px 宽/72px Logo 区/40px 行与 14px 字级排布，傻瓜设置置顶，分隔线后依序网络环境、Claude 身份管理、浏览器环境、电脑环境、使用说明；全局任务锁控制导航，底部本地版标识与界面语言不挂载更新器。
navigation.ts / navigation.test.ts: 本机页面偏好白名单、存储失败回退身份页；不存账号或路径。
help.tsx: 双语只读本地产品说明，身份/浏览器/离线额度/网络诊断/电脑设置五项编号说明保留操作后果，details 折叠应用使用、账号边界与申诉；不读取用户资料或调用原生命令。
identities.tsx: 默认开启的浏览器联动开关/旧资料采用确认、独立资料标记和浏览器重开失败重试；空身份固定最左、当前账号其次的竖式 196×312 工牌，单排横向卡片，顶部挂孔绿光表示当前身份、展示离线 5h/7d 剩余额度与重置倒计时徽章、推荐切换标记及一键切到最优号按钮，无障碍名称保留状态语义；Motion 弹簧滚轮/轻微悬停视差（按钮区冻结，卡片内部保持平面命中测试），原生媒体订阅使减弱动态偏好实时停止动画；滚动条/键盘保持原生，无分页或数量截断；当前账号支持原地加密备份（不清空工作区）、卡片直接切换、专用停止进程命令不扫描历史、折叠保留选项、名称、切换/恢复/永久删除 Alert 警告（需勾选确认，默认聚焦取消）；协调文件残留/CLI 的任务锁，身份变更使旧残留预览失效；凭据不进 UI。
identity-model.ts: 浏览器绑定脱敏状态与 SQLite 受限目录、当前/暂存显示字段（含离线 5h/7d 额度百分比与重置时间戳）和保留策略契约，Skills/插件/MCP/个人设置/项目记录/历史/缓存逐项由用户选择。
claude-cli-panel.tsx: 身份页内的 CLI 维护；复用安全进程结束和官方卸载/重装，保护保险库与个人资料。
claude-residue-panel.tsx: 身份页内用户触发的固定 Claude 文件扫描、路径/字段名/大小/影响预览；仅完整缓存默认勾选，登录/历史/备份独立选择，不完整项禁选。直接清理使用默认取消的 Alert 与勾选确认，成功/失败均复查且清空选择；不访问钥匙串、通用配置或浏览器资料。
cleaner-activity.tsx: 单次调用隔离的 ActivityController 与身份卡片正下方 IdentityOperationProgress；身份/空身份/残留清理共用真实事件阶段、局部 n/N 与脉冲，不预填步骤或按时间推算百分比，未知总量只显示运行。失败/回滚/完成带警告分开呈现，保留实际耗时和原始日志用于即时切换语言；其他页面沿用 CleanupActivity。
cleaner-model.ts: 文件残留快照类型与选择规则、POSIX/Windows 路径父子去重、子项排除、重扫编号映射与规模格式化，供预览和执行共享。
cleaner-model.test.ts: 预设、跨平台父子选择隔离与重扫不扩大选择的回归，不调用清理命令。
system.tsx: 电脑环境页，当前状态与目标草稿分离；时区、语言和定位各自应用；钥匙串解锁与系统授权入口归入本页；Windows 隐藏不适用的钥匙串按钮和辅助功能要求，使用实际系统授权状态。
index.css: 系统字体与中性黑白基础主题入口，共享控件扫描；Landing 的几何与纹理归 style.css。
locales/: 双语 YAML 目录及导入类型，包含使用说明页的操作、安全和账号风险文案；见其 CLAUDE.md。

i18n.test.ts: 双语键/插槽一致性、界面文案覆盖、原生错误与语言切换回归；不访问真实设置。
local-edition.tsx: 侧栏只读本地定制版标识与本机版本号，不发起网络请求或更新检查，不参与任务锁；版本读取失败时仍保留本地版标识。
language-switch.tsx: 极简中英文切换；宿主原子持久化成功后更新界面，失败保留原偏好并显示错误。
dialog.tsx: Radix Dialog/AlertDialog 受控模态，警告阻止遮罩误关闭且默认聚焦取消；无 Trigger 时的原焦点恢复与读屏标题/描述，ModalShell 关闭按钮支持当前语言、底部操作自动换行。
