# Free 养号身份卡

身份管理页在 CLI 身份库下方提供独立的 Free 养号卡区域。每张卡拥有永久身份 ID、独占浏览器槽位与确定性指纹种子，并维护待注册、已过 KYC、Free 养号中、Pro 待转正四个阶段。名称、可选邮箱、简短备注与起算日期可编辑；Day N 和今日打开标记按系统本地自然日显示。打开网页只记录当天已打开，不证明网页内已完成聊天、注册或 KYC。

新建卡片默认仅切换浏览器槽位，也可明确选择打开本地核验页或 Claude.ai。卡片菜单可打开这两个页面、选择当前浏览器槽位、编辑信息、补录订阅日期、转正及删除。当前槽位同时决定「浏览环境」和「风控验证」使用的配置。切换槽位会先正常退出旧槽位的浏览器；普通养号操作不会停止 Claude CLI、替换 CLI 配置或修改 CLI 当前身份指针。

当前浏览器选择为有效养号卡时，普通 CLI 身份切换、保存及删除会保留该养号槽位和窗口，不再关闭养号浏览器或自动改选为 CLI 身份的浏览器。CLI 身份继续维护自身独立绑定。显式养号转正、浏览器联动设置和未完成事务恢复仍使用原有浏览器关闭与阻断保护；操作失败且遗留恢复检查点时也不会绕过保护。

浏览器资料的持久选择与实际运行分开显示。关闭窗口后保留原资料、槽位及种子，养号卡显示「已关闭」，完整提示说明资料仍被选中；只在观察到窗口运行时显示运行状态，无法核实时保留未知。身份页和浏览环境仅在页面可见时低频读取当前槽位的进程/窗口状态，不查询账号额度或凭据。

身份与养号两栏共用数量标签样式，分别显示「张身份卡」与「张养号卡」。养号四步精简为新建卡片、配置并核验、注册与日常使用、升级后转正；邮箱行与正式浅底卡共用主题颜色，同时保持隐私遮罩。卡头使用完整可见的短状态，详细归属放入提示，相关文案不采用装饰性中点分隔。

当前 CLI 卡和浏览环境提供「返回当前 CLI 浏览器并核验」。确认窗说明会关闭当前浏览器窗口，用户应先保存网页任务；后端只使用已证明的当前 CLI 既有绑定，不停止 CLI、不改 CLI 配置或当前身份、不生成新槽位或种子。失败会报告实际完成范围，回滚选择不等于旧网页窗口已自动重开。

浏览环境分别显示 CLI 身份与当前浏览器身份，风控页携带同上下文的遮罩被测浏览器归属。20 项核验仅描述当前浏览器环境，不验证网页登录账号或 CLI 服务授权；不需要持续重测来维持 CLI 登录。当前 CLI 的「打开官方用量页」使用冻结账号指纹对应的独立资料，不随养号浏览器选择改变，也不改全局核验会话或写入额度账本。

独立资料目录和指纹不等于网络出口独立，也不保证服务端接受账号请求。代理留空或共享网络配置时仍可能共用出口。网页登录与 CLI 同时使用时出现的 HTTP 403 必须保留实际响应证据，不能仅凭本地隔离测试判定原因或声称授权已恢复。

Windows 默认浏览器入口对明确的 Claude OAuth 授权链接增加私有保护：养号槽位正在使用时，严格匹配的 PKCE/回环回调授权链接只会打开到经本地当前 CLI 账号证明的既有独立浏览器资料，不改当前养号槽位、Cookie、会话或全局启动参数。证据不足会显示固定提示并拒绝回退到养号资料。保护仅覆盖已定义的 `claude.ai/oauth/authorize` 授权形状；普通登录、支付链接和显式转正保持原行为，不声称覆盖所有 CLI 版本或浏览器内部导航，也不自动同意授权。

风控页的六项检查与浏览器二十项检查保持不同范围。DNS 审计展示配置来源和具体缺项，远程加密 DNS 已存在时不再提示补齐；未验证来源、未知值和不完整解析保持待核验。HTTP 出口实测不称为 DNS 抓包或账号安全保证；按浏览器槽位、配置版本和有效代理上下文冻结采样，期间变化或前后不匹配会拒收，刷新及焦点变化不会沿用旧结果。

手机 LAN 桥接口令必须使用安全随机数生成器；随机源缺失或失败时停止相关口令/配置/二维码生成并显示原因，不再生成固定回退口令。只读诊断与用户自行填写认证的独立桥接路径保持可用。

养号元数据使用独立的私有 `identity-vault/warming_cards.json`，限制为 128 KiB、128 张卡，执行格式校验和原子写入。浏览器绑定继续使用既有 SQLite 表，不向正式身份表放入空归档。代理值、凭据与 Cookie 不会进入卡片的前端契约。手动充值日和到期日仍保存在独立订阅文件中，日期时间戳保持 UTC 正午锚点。

网页升级 Pro 后，先把卡片阶段改为「Pro 待转正」，再选择转正操作。此操作明确展示对运行中 CLI 的影响，并复用现有确认、进程检查、归档和失败回滚流程。确认后用户在终端完成 CLI 登录，再保存身份。保存后的正式 CLI 卡继承养号卡的 ID、浏览器槽位、指纹种子、原资料目录和手动订阅日期；程序不会复制、合并或重新生成养号浏览器资料。额外的转正标记区分受控转正与普通浏览器草稿，防止把切换前的 Pro 账号错误保存为养号卡。

删除默认保留浏览器资料，删除资料需要另行勾选并确认。删除当前养号卡前，程序先正常退出该浏览器并转到全新空白槽位，因此只有一张养号卡时也可删除，且不需要切换 CLI。删除受既有进程、路径与私有目录检查约束；部分清理失败会明确报告。

在 `v0.2.3` 中，养号卡片与安全边界进一步扩展：
- **常驻国家/时区锁定与打开前防漂移确认（F3）**：首次通过伴生浏览器完成环境核验并锁定有效地区时，卡片自动记录 `registered_country` 与 `registered_timezone`；后续点击打开前若检测到当前出口国家与锁定国家不一致，弹出警示确认框（支持取消、仍要打开或更新锁定地区并打开），并在 `180×286` 卡片环境行内联显示紧凑漂移徽章。
- **阶段防封 SOP 折叠指南（F4）**：新建/编辑弹窗底部内嵌默认收起的阶段化防封操作参考建议，不占用主界面卡片高度。
- **跨槽位 CLI 订阅同步与断路器协同（F1 & 阶段 B）**：即使当前选中养号卡槽位，当前 CLI 身份也可直接定位并打开其已绑定的独立 CLI 浏览器资料完成「同步订阅日期与额外重置」；伴生浏览器按需断路器（Kill-Switch）在检测到系统 TUN 断开（5s 连续两次）或出口国家漂移（60s）时优雅关闭运行中的受管伴生浏览器并点亮红色提醒，恢复后一键重开零阻断，全程绝不中断 `claude.exe`。
- **全链路 `.clbackup` 加密备份覆盖（F6）**：`identity-vault/warming_cards.json` 与 `identity-vault/manual_subscriptions.json` 已纳入 `.clbackup` 口令加密导出、完整性预检（含 `browser_bindings` 槽位与正整数种子校验）、启动前自动救援备份与隔离恢复副本；浏览器用户数据目录（`browser/contexts/*`）仍保持在归档体积之外。

验证使用临时目录、虚构账号、隔离浏览器与模拟 IPC，覆盖 CLI 指针/配置不变、槽位与种子稳定、国家漂移拦截、SOP 折叠、转正/回滚、订阅继承、全链路备份恢复、双语卡片和界面交互。实际注册、KYC、充值与真实账号转正由用户操作，自动化验证不调用这些服务。
