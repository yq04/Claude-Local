# 0.2.0 界面精修、API 等效成本分析与新一代悬浮监控窗

`v0.2.0` 聚焦日常高频工作流的视觉减负、信息密度优化与桌面级实时监控体验升级，完成九项核心改进：

## 1. 新一代桌面悬浮监控小窗（HUD）

借鉴 Token Monitor 的实时遥测呈现思路，并与 Claude-Local 的毛玻璃表面风格、强调色及自定义壁纸体系深度融合：

- **三态几何自适应**：
  - **展开模式（`340×258`）**：完整展示激活身份、订阅档位（Pro / Max 5x / Max 20x）、`5h $X.XX` 实时成本徽章、5h / 7d 双窗口剩余额度进度条、重置倒计时、5h 耗尽预估（`⚠ ~1h10m`）、当前主力模型占比及底部三栏实时遥测卡（`5h 消耗 + 缓存命中率`、`实时速率 tok/m + 路由隔离状态`、`5h 等效花费 USD + 缓存节省 USD`）。
  - **紧凑模式（`340×152`）**：一键折叠底部遥测明细，仅保留账号状态与 5h / 7d 双窗口核心进度。
  - **侧边胶囊模式（`52×138`）**：支持手动收起或贴边自动隐藏为 52px 宽的侧边迷你胶囊，纵向展示运行呼吸灯、5h 剩余百分比与迷你进度条。
- **桌面级窗口交互（置顶 / 锁定 / 磁吸 / 贴边自动隐藏 / 透明度）**：
  - **窗口置顶（Pin）与位置锁定（Lock）**：支持一键切换常驻置顶与坐标锁定，锁定后防止误触拖拽。
  - **18px 边缘磁吸（Magnetic Edge Snap）**：拖拽释放或移动停止时自动检测当前显示器工作区（Work Area）四边，距离小于 18px 时平滑吸附对齐并持久化保存停靠边（`left / right / top / bottom`）。
  - **贴边自动隐藏（Edge Auto-Hide）**：吸附在屏幕左/右边缘并开启自动隐藏后，鼠标移出小窗约 420ms 自动收缩为侧边胶囊，鼠标悬停或点击即刻展开为完整面板。
  - **无级透明度调节（50%–100%）**：标题栏内置透明度面板（支持滑块无级调节、50% / 65% / 80% / 95% / 100% 快捷档位及右键循环切换）。
- **主题与自定义壁纸实时联动**：通过 `BroadcastChannel` 与 `storage` 事件实时同步主窗口的浅色/深色主题、四套强调色、表面材质、背景氛围及自定义壁纸（自动叠加高可读性毛玻璃遮罩）。

## 2. 用量分析：API 等效美元花费与同行时间范围

- **同行时间范围展示**：将筛选时间区间与时区标识（如 `2026年10月6日 – 2026年10月26日 EDT`）移至 `[今天 | 昨天 | 近7天 | 近30天 | 全部]` 右侧同行区域，消除纵向空白。
- **六维次级指标横条**：将原三项次级统计扩展为六项单行指标栏（`去重响应数 | API 等效花费 | 缓存节省 | 单次均值 | 缓存写入 | 缓存读取`）：
  - **API 等效花费（USD）**：基于 Anthropic 官方 Claude API 模型单价（区分 Claude Opus 4.x、Sonnet 4.x、Haiku 4.5 / 3.5 的输入、输出、缓存写入与缓存读取单价）自动核算当前筛选范围内的等效 API 美元成本。
  - **缓存节省（USD）**：自动计算 Prompt 缓存读取相比未缓存输入所节省的美元成本（绿色高亮展示）。
  - **单次均值**：展示每次去重响应的平均 Token 吞吐量。
- **按模型成本明细**：右侧「模型分布」列表在展示响应次数与输出 Token 的同时，直接标注各模型的等效美元花费（如 `614 次响应 · 输出 295K · $7.12`）。

## 3. 身份管理与「联动浏览器」切号自动打开

- **顶部工具栏一体化重构**：将右上角「自动续杯 + 时间段」、「悬浮监控窗」、「同步本地额度」与「更多操作」重构为统一 `30px` 高度的分段胶囊与操作栏，视觉层级清晰、紧凑对齐。
- **「添加新号 3 步法」减负**：移除引导条右侧冗余的「打开内置浏览器」按钮，保持三步流程（`点「新身份」归档旧号 → 内置浏览器验证并登录充值号 → Claude Code CLI 继续授权`）直观纯粹。
- **「联动浏览器」切号自动弹出验证页**：修复勾选「联动浏览器」后切换账号时若内置浏览器未处于运行状态则不会自动弹出的问题；现在勾选联动后切换账号，会自动以新账号专属隔离资料启动内置浏览器并打开检测与登录验证页面（单元与无头测试可通过 `skip_browser_launch` 安全跳过）。

## 4. 导航栏、浏览环境、电脑环境与使用说明精简

- **左侧导航栏美化与搜索框移除**：移除左下角冗余的「命令 Ctrl K」搜索框（保留 `Ctrl+K` 快捷键呼出能力），为当前选中项增加左侧 `3px` 主题色指示条与柔和渐变胶囊背景，并将底部语言切换 `[CN | EN]` 与版本号徽章 `v0.2.0` 整合为单行底栏。
- **浏览环境顶部卡片精简**：移除「启动内置浏览器与 CLI 授权联动」卡片中冗余的 `绑定身份`、`Chromium 版本` 胶囊以及极少使用的 `正常退出浏览器`、`设为默认浏览器` 按钮，仅保留核心运行状态与「打开浏览器并实测 / 重新打开实测页」主操作按钮。
- **电脑环境标题栏精简**：移除右上角低频冗余的「查看/恢复本次环境修改」、「系统授权设置」与「刷新状态」按钮，保持页面聚焦于系统状态展示与浏览器环境比对。
- **使用说明页面清理**：移除底部的「任务交接模板」组件，使帮助文档页面专注呈现使用指南与排障说明。
