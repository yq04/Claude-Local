# Claude-Local 0.1.7

> 开发过程归档，不作为对外发行序列。Claude-Local的发行版本从0.1.0开始；当前版本与下载以README和Releases为准。以下源码/哈希/测试记录保持原值，不代表当前发布状态。


引入六项生产力与诊断增强，加固额度解析与 CLI 状态检测弹性，并在原生层实现基于 IANA 命名时区的历史夏令时日历边界与真实时长统计。改动已完成针对性测试与构建检查；是否已构建安装包、部署或发布，以本次交付回执为准。

## 身份检索、排序与诊断透明化

- 隐私安全检索与 Esc 清除：身份列表支持可见别名搜索，隐私遮罩开启时不按隐藏邮箱或名称匹配；支持名称、最近保存及原顺序排序，当前激活身份固定显示，Esc清空搜索。排序只改变视图，不改原生记录顺序。
- 逐窗观测新鲜度与状态分层：针对 5h 与 7d 额度窗口分别计算并展示观测时间与分钟级新鲜度（age）；将配置检测（config）、采集脚本（script）与运行时（runtime）明确区分为独立状态，未实测执行的环境如实标记为 runtime unverified，不冒充真实验证。
- 白名单诊断信息复制：提供格式化诊断复制功能，严格限定仅输出应用版本、生成时间、标准化窗口来源与观测年龄、采集配置状态标志等白名单字段，坚决杜绝个人路径、账号标识、凭据或原始终端内容外泄。

## 快捷命令面板与受控导航

- 快捷呼出与焦点恢复：支持 Ctrl+K / Cmd+K 呼出命令面板，键盘上下导航、Home/End、回车选择及Esc退出；活动项自动滚动可见，关闭后恢复到可用触发入口。
- 活动页面就地刷新：支持通过命令面板直接触发当前活动页面（清理、快速配置、伴生浏览器、系统环境、用量统计等）的数据刷新，复用各页面既有防抖与加载保护。
- 受控身份切换审核：命令面板仅支持查找与呼起已保存身份的确认审查弹窗，绝不绕过二次确认直接触发原生切号逻辑。
- 严格操作守卫拦截：当系统处于后台任务忙碌（busy/locked）、输入法候选组合（IME composing）、表单输入处于焦点（editableTarget）或其他模态对话框打开时，严格抑制快捷键触发，防止操作冲突。

## 结构化离线交接模板

- 纯内存手填六字段：内置任务交接模板（包含 task、goal、progress、next、verification、constraints 六项手填字段），各字段长度设上限且仅保存在调用方内存中，严格不读取历史会话记录、项目文件或本地凭据。
- Markdown 文本预览与下载：提供结构化文本预览、复制全文和用户显式下载；关闭再打开保留本次内存草稿，退出应用后不自动持久化，不读取会话或项目内容。

## 聚合用量导出与公式安全防护

- 仅导出当前已渲染快照：用量统计导出严格基于当前界面已筛选渲染的聚合数据（totals / daily），不遍历全库原始日志。
- 双模式输出与隐私模式兼容：支持 TSV 格式的一键复制与文件下载；在开启隐私模式时，自动对敏感账号标识进行遮蔽。
- 电子表格公式防护：对危险公式前缀加文本保护，并正确转义制表符、换行和双引号。不额外导出隐藏未归属桶、独立推理指标或未来零值。

## IANA 真实时区日历边界与夏令时兼容

- 命名时区与日历边界对齐：原生用量统计支持接收标准的 IANA 时区标识（如 America/New_York、Australia/Lord_Howe），精确计算并对齐夏令时切换日的自然日历零点，妥善处理午夜缺失或歧义的历史特殊时间点。
- 23/24/25 小时日及特殊偏移处理：完整支持夏令时转换引起的 23 小时短日与 25 小时长日，并在内部计算真实小时时段（含 Lord Howe 等 30 分钟特殊偏移），同时完全保留旧版固定分钟偏移（offset_minutes）的向下兼容调用。
- 真实区间加权平均：小时均值按已发生区间的实际长度折算，不把半小时槽当成一整小时；当前未结束的槽仍沿用完整区间计入的口径。峰值显示真实时段及其总量。

## 额度解析加固与 CLI 稳定性修复

- 畸形输入防御与摘要演进：加固 Python 与 Rust 额度核心对极端数值、负数、布尔值及非有限数输入的边界检查，过滤非法锚点并容忍 100%–101% 的浮点舍入微差；额度摘要版本递增至 7。
- CLI 读取错误重试与双语引导：分离 CLI 初始状态读取失败与安装/更新失败状态，读取异常时不再误报“未安装”，提供就地重试按钮与双语排错指引。
- 统计范围说明修订：纠正“未归属历史单列”的旧说明，与当前“全部/已保存账号”筛选及显式稳定兜底聚合保持一致。

## 架构边界与格式兼容性

- 存储与加密协议不变：SQLite 数据库保持 user_version=3，BAGAID01 签名、.baga 归档编码、账号 HMAC 算法及伴生浏览器种子域名机制完全保持一致。
- 账本写入边界：Python继续作为quota_ledger唯一写入者，保留跨进程锁与原子替换；Rust只读该额度账本，Token统计继续使用独立的原生用量账本，不新增OAuth用量轮询。
