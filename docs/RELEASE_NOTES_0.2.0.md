# Claude-Local 0.2.0

`Claude-Local 0.2.0` 带来全新的 **Token Monitor 风格桌面悬浮监控小窗（HUD）**、**基于官方 Claude API 定价的美元等效花费与缓存节省分析**、**勾选「联动浏览器」切号自动打开新账号浏览器验证页**，以及覆盖全工作区的界面减负与排版美化。

---

## 核心亮点

### 1. 全新桌面悬浮监控小窗（HUD）
- **多形态自适应布局**：支持 **展开模式（`340×258`）**、**紧凑模式（`340×152`）** 与 **侧边胶囊模式（`52×138`）**，完整显示 `重置 2h 15m` 与 `⚠ ~1h10m` 耗尽预警，消除窄窗文字截断。
- **Token Monitor 风格三栏实时遥测**：底部集成 **5h 消耗（含缓存命中率）**、**实时速率（`tok/m` + 路由隔离状态）** 与 **5h 等效花费（`$X.XX` + 缓存节省 `$X.XX`）**，并在账号行直观展示当前主力模型调用次数及占比。
- **置顶、位置锁定、边缘磁吸与贴边自动隐藏**：
  - 支持一键 **置顶（Pin）** 与 **锁定位置（Lock）**；
  - 拖拽靠近屏幕四边 18px 内自动 **磁吸对齐（Magnetic Edge Snap）**；
  - 开启 **贴边自动隐藏（Edge Auto-Hide）** 后，停靠在屏幕左右边缘的小窗在鼠标移出后自动收缩为 `52px` 侧边迷你胶囊，鼠标移入或点击即刻展开。
- **无级透明度与主题/壁纸同步**：内置 **50%–100% 透明度滑块与快捷预设**（支持右键循环切换），并实时同步主软件的浅色/深色模式、强调色、预设背景与自定义壁纸。

### 2. 用量分析：API 等效美元花费与同行时间范围
- **同行时间范围**：将当前筛选日期区间与时区标识（如 `2026年10月6日 – 2026年10月26日 EDT`）移至 `[今天 | 昨天 | 近7天 | 近30天 | 全部]` 右侧同行空白处，版面更紧凑。
- **6 项核心遥测横条**：在四大 KPI 卡片下方提供单行六维统计（`去重响应数 | API 等效花费 | 缓存节省 | 单次均值 | 缓存写入 | 缓存读取`），按 Anthropic 官方 Claude API 模型单价自动计算 **API 等效花费（USD）** 与 **Prompt 缓存节省金额（USD）**。
- **模型成本分布**：右侧「模型分布」同步显示每个模型家族的调用响应次数、输出 Token 与等效美元花费。

### 3. 身份管理与内置浏览器联动增强
- **顶部工具栏一体化**：右上角 `[• 自动续杯 | 08:00–23:00] | [• 悬浮监控窗] [↻ 同步本地额度] [⋯]` 采用统一 `30px` 高度胶囊与按钮组设计。
- **三步法引导栏精简**：移除「添加新号 3 步法」右侧冗余的「打开内置浏览器」按钮。
- **切号自动打开联动浏览器**：勾选「联动浏览器」后切换身份时，无论内置浏览器此前是否开启，均自动拉起新切入账号对应的隔离浏览器并打开环境检测与登录验证页。

### 4. 全局界面减负与导航栏美化
- **左侧导航栏升级**：移除底部冗余搜索栏（保留 `Ctrl+K` 快捷键呼出命令中心），新增当前页左侧 `3px` 强调色指示条与渐变激活态，底部 `[CN | EN]` 与 `v0.2.0` 版本徽章合并为单行。
- **浏览环境顶部精简**：移除「启动内置浏览器与 CLI 授权联动」卡片中多余的 `绑定身份`、`Chromium` 标签及右侧 `正常退出浏览器`、`设为默认浏览器` 按钮，仅保留主启动按钮。
- **电脑环境与使用说明精简**：移除电脑环境右上角「查看/恢复本次环境修改」、「系统授权设置」、「刷新状态」按钮；移除使用说明页面底部的「任务交接模板」板块。

## 安装与升级说明

- **Windows 10 / 11 x64 安装包**：`Claude-Local_0.2.0_x64-setup.exe`
- **数据兼容**：完整兼容已有 `%APPDATA%\ai.local.claude-local` 身份库（`BAGAID01` / `.baga` / SQLite `user_version = 3`）、加密备份与专属浏览器资料目录，升级过程无需重建身份或中断正在运行的 `claude.exe` 终端会话。
