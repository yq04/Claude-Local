# Claude-Local 0.2.0

> 开发过程归档，不作为对外发行序列。Claude-Local的发行版本从0.1.0开始；当前版本与下载以README和Releases为准。以下源码/哈希/测试记录保持原值，不代表当前发布状态。


本版引入功能可靠性加固与在线额度编排能力，完善运行环境能力探测、系统设置修改审计、带口令加密备份救援与手工交接模板。构建产物哈希、CI 审计与安装更新状态以独立交付回执为准。

## 运行资源与环境能力探测

- 资源清单与哈希校验：构建、审计和部署按受控清单比对资源哈希；运行时检查固定路径组件及解释器能力。
- 解释器探测与密码学能力核验：内置无账号运行探针，前置检测系统 Python 3.10+ 及 `cryptography` 库的 AES-GCM 可用性，优先使用合格系统解释器。
- 运行边界拦截：对未达标或损坏的环境明确报错拦截，防止隐式降级。

## 系统环境修改记录与安全回退

- 前后快照审计：修改系统设置前先在私有目录记录修改前（before）快照，执行后记录实际（after）状态。
- 变更保护：恢复计划校验字段状态，若检测到目标字段已被用户在外部另行修改，则拒绝盲目覆写，不假定未知状态可恢复。
- 浏览器对齐与协同恢复：接入浏览器环境对齐入口，支持时区与语言同时恢复时的多字段范围保护。

## 认证归档与最小读取

- 认证帧保护：共享解码器校验 BAGAID01 认证结束帧，拒绝多余尾部数据。
- 最小必要只读提取：在线额度查询仅在内存读取必要账号元数据、授权和路由，不解包工程正文与会话内容。
- 格式支持：支持 gzip 与 Windows 平台实际 Zstd 压缩归档格式，维持资源激活与路由隔离。

## 统一额度任务与前台在线查询

- 原生有界任务快照：原生层保留有界任务快照，页面切换可恢复进度或显式取消；任务快照随原生进程生命周期管理。
- 冻结指纹与终态：每次发起查询冻结当前账号指纹，所有查询目标均有确定终态。
- 一次性许可核验：网络等待不占身份事务门，提交前通过一次性许可（one-time permit）核验账号代次、凭证及路由。
- 单一写入者：Python 进程保持为额度账本唯一写入者，执行跨进程锁与原子替换，Rust 保持只读并进行内存合并。
- 前台聚焦检测：近实时统一前台刷新默认关闭，开启时仅在身份管理页面可见且窗口聚焦时运行，不增加后台轮询。

## 代理支持与安全边界

- HTTP CONNECT 隧道支持：支持通过无认证 HTTP 代理经 CONNECT 隧道访问 HTTPS 目标。
- 明确拒绝不支持类型：对未支持的 HTTPS 自身传输代理、SOCKS 代理或需要认证的代理类型明确拒绝。
- 禁止静默直连：代理连接失败或类型不受支持时不降级为直连，避免意外网络外泄。

## 伴生浏览器与权益桥接

- MV3 内容脚本通信：通过受控 MV3 扩展与当前运行中的管理浏览器资料通信，支持自动注入、worker 恢复、票据过期检测与正文尺寸上限防护。
- 订阅日期与重置余额：从合法响应中提取订阅到期时间与平台手动重置额度，按本地保守有效期保存。
- 零余额与状态区分：修正零余额因缺少正余额字段被误判未知的逻辑，明确区分需更新状态与真实零余额。

## 用量归属规则与别名脱敏

- 稳定账号规则归属：支持按稳定账号 ID 预览并设置历史或未归属 Token 记录的汇总归属规则，不修改底层原始事件日志。
- 支持随时撤销：归属规则支持显式撤销并即时恢复原始聚合视图。
- 敏感信息脱敏：账号别名包含邮箱等敏感身份信息时，界面与导出执行脱敏遮罩。

## 集中恢复队列与接入排障指引

- 异常待办聚合：将网络异常、授权失效或需处理的账号集中归入恢复队列，保留已有正常账号结果。
- 明确交互绑定：支持用户显式点击重新打开该账号专属绑定的浏览器资料，不切换当前 CLI 槽位或修改浏览器种子。
- 官方安装命令与排障：CLI 未安装时提供官方安装命令一键复制及就地重新检测，不自动执行远端脚本。

## 安全备份与加密救援

- 口令加密外发备份：采用 PBKDF2-HMAC-SHA256 密钥派生与 AES-GCM 认证加密保护包含主密钥的备份包；正常备份基于 SQLite 在线快照生成，校验白名单与完整槽位清单。
- 隔离救援证据保存：损坏或异常的本地资料可打包导出为显式标注为“未验证”的加密救援证据，避免原始数据彻底丢失。
- 独立恢复副本机制：从备份中恢复时，在独立私有目标路径下生成已验证的恢复副本（Recovered Copy），不会自动激活、直接并入或覆盖当前活动的身份库；恢复副本不包含未保存的当前 CLI 临时状态或浏览器资料。

## 结构化手工交接与界面改进

- 显式导入与导出：内置任务交接模板支持从用户选择的本地 Markdown 文件载入或导出，限制单个文件 64KiB 上限及六个字段各 2000 字符上限。
- 防误触确认：载入新文件替换当前非空草稿前，弹出结构化文本预览并经用户确认。
- 离线内存草稿：手填交接草稿仅保存在内存中，关闭应用不持久化，不扫描工程文件或会话记录。

## 安全边界与外部依赖声明

- 外部 Python 3.10+ 及 Cryptography 依赖：额度在线查询、备份加解密及账本写入依赖外部提供的 Python 3.10+ 及 `cryptography` 库，安装包不自动捆绑 Python 环境。
- 代理协议限制：仅支持无认证 HTTP CONNECT 代理访问 HTTPS 目标；不支持的代理协议明确拒绝，不隐式降级直连。
- 备份恢复为独立副本：备份恢复产物仅生成在独立的私有目录中作为隔离恢复副本，不覆盖当前活动身份库，不自动激活或执行数据库合并。
- 真实账号与系统修改验收边界：功能已完成分层合成验证与沙箱断言，真实 Anthropic 账号在实际服务器上的接口授权与实际 Windows 系统级安装/修改验收属于人工环境验收范畴。

## 交付与验证范围

本版改动已通过分层合成测试（Python 探针与在线额度、Rust 原生核心、UI 模型与浏览器交互）及 TypeScript/Vite 构建检查。正式包的 CI 流程、隐私审计、安装包哈希及发布回执按交付规范独立记录。
