# 0.2.1 用量可靠性与监控调整

本文记录未单独公开发行的本机维护候选。正式 v0.2.2 保留统计可靠性改动，并将界面简化为“全部”和正常账号筛选；内部历史规则及归属状态不在界面呈现，详见 [0.2.2 发布说明](RELEASE_NOTES_0.2.2_USAGE.md)。

新账号登录后，身份卡可以立即读取到账号资料，而旧版 Token 归属必须等待保存归档或显式切换完成。直接使用 CLI 时，中间记录可能留在未知区间；全局默认归属又将这些记录显示到旧账号。此次将统计身份登记与归档生命周期解耦，保持凭据、归档协议和已有归属证据不变。

统计账本以现有账号/组织 HMAC 登记独立身份，不创建假的身份归档，也不停止 CLI。经应用显式清空身份且已通过原有进程检查的登录窗口，有独立来源回执，可以给新账号接力旧会话的新响应建立统计归属。外部登录变化不具备相同证据时，只接纳可验证的新会话，无法判断的旧会话保持未归属。历史未知事件不因后来发现账号而自动改写。

旧的默认归属只保留在固定历史截止范围内，后续未知用量不会继续静默流入该账号。“全部”包含未知及无法映射旧账号的事件，提供未归属筛选与提示。精确历史修复必须单独确认范围、做一致性备份并校验记录集合；不会通过修改全局兜底转移全部历史。

会话数只来自明确 sessionId 的域隔离哈希；旧解析游标升级时补齐证据，保持已有账号归属。按请求标识去重并合并累计用量，主会话优先于同标识的 sidechain 回放。Token 总量仍为未缓存输入、输出、缓存写入和缓存读取之和，推理量已经包含在输出中。

用量页突出总 Token 与四类构成、缓存命中、真实会话与活跃日、去重响应及模型分布。保留时间/账号筛选、IANA/DST、趋势/数据视图、隐私遮罩和范围内 TSV 导出。移除 API 等效美元与缓存节省金额，避免将模型猜价误作订阅支出。

额度小窗使用同一账本并严格核对当前账号，展示近五小时四类 Token、缓存命中、最近有证据的模型、近十分钟固定窗口 tok/min 与去重响应。没有可信账号证据或账本读取失败时显示未知，不复用其他账号数据。移除假定上下文容量和无时间序列支持的触顶推算；保留额度来源、重置倒计时、三态尺寸、置顶、锁定、磁吸、自动隐藏、透明度与主题同步。

CLI 的累计统计缓存与当前 JSONL 去重统计不是相同的数据集。排查差异时应独立提取数值元数据，分别比较原始行累加、请求去重、主会话优先和账本，并明确刷新时差；不能只按两个界面的总数判断哪一方错误。应用不修改 CLI 的统计缓存。

验收使用合成身份、会话和隔离浏览器上下文，覆盖未归档账号、续聊、外部登录歧义、未知总量守恒、历史截止、重放与会话迁移，以及中英文窄窗口。当前为本机维护修订，公开发行仍以既有不可变 Release 记录为准；没有移动标签、发布更新端点或替换既有安装包。
