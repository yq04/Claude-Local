# Contributing to Claude-Local

This is an independently maintained Windows project. Changes are driven by local usability, correctness and safe data handling. Read AGENTS.md, NOTICE.md and docs/DEVELOPMENT.md before changing code.

Use synthetic fixtures, preserve existing on-disk formats, and include focused regression tests for correctness fixes. Keep all user data and machine-specific configuration out of commits. Do not add an upstream auto-sync, official update channel, affiliate links or release credentials.

The repository currently uses private checks and manually dispatched build artifacts. Releases, broader platform support and public redistribution are separate deliberate decisions; third-party license boundaries must be resolved before a public distribution.
