# Contributing to Claude-Local

This is an independently maintained Windows project. Changes are driven by local usability, correctness and safe data handling. Read AGENTS.md, NOTICE.md and docs/DEVELOPMENT.md before changing code.

Use synthetic fixtures, preserve existing on-disk formats, and include focused regression tests for correctness fixes. Keep all user data and machine-specific configuration out of commits. Do not add an upstream auto-sync, official update channel, unauthorized promotional links, automatic external navigation or release credentials. The project owner authorizes fixed referral links bundled with the software exclusively as copy-only actions; do not add recipient-facing link editors, per-install overrides or automatic external routing.

The repository currently separates automated repository checks from manually dispatched private build artifacts. Continuous integration executes validation and synthetic tests without automatic public releases. Public release workflows and broader redistribution remain separate deliberate decisions; third-party license boundaries (including vendor components documented in NOTICE.md and docs/DISTRIBUTION.md) must be resolved before public source or binary distribution.
