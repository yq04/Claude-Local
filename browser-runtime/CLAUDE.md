# browser-runtime/

Optional, independently integrated Fingerprint Chromium subsystem. The pinned version, preparation script and upstream engine copyright are dependencies, not product update or release control. WindowsBrowser/ is ignored and contains no user profiles; user data resides in the application's private data root. Current browser icon is the Claude-Local CL/B mark. The companion is launched only by an explicit action or --browser and is bundled with the main application for Windows.

Do not commit the engine, generated archives or user profiles. Keep all engine credits/licenses intact. Other platform boundary source is retained for future work; only Windows x64 is currently supported and validated.
