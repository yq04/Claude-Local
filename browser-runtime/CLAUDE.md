# browser-runtime/

Optional, independently integrated Fingerprint Chromium subsystem. The pinned version, preparation script and upstream engine copyright are dependencies, not product update or release control. WindowsBrowser/ is ignored and contains no user profiles; user data resides in the application's private data root. Current browser icon is the Claude-Local CL/B mark. The companion is launched only by an explicit action or --browser and is bundled with the main application for Windows. `quota-bridge/` holds a fixed three-file MV3 extension that runs only on a sync URL opened by the explicit subscription-sync action, uses fixed Claude and loopback origins, and never reads cookies or installs polling alarms. Its local pairing fragment includes the existing 64-hex quota_identity fingerprint; the service worker compares bounded account UUID/email and organization UUID candidates against that fingerprint, retains it only in session storage, and forwards metadata only for one unique match. The content script checks the account and selected organization again after usage fetches, rejects challenge/redirect responses, and applies a 20-second overall, five-second per-request, and 512-KiB body bound. The fingerprint never appears in a Claude URL. `scripts/test-quota-integration.mjs` loads the packaged extension files in a fresh temporary Chromium profile, blocks external traffic, and uses intercepted HTTPS plus loopback synthetic responses.

Do not commit the engine, generated archives or user profiles. Keep all engine credits/licenses intact. Other platform boundary source is retained for future work; only Windows x64 is currently supported and validated.
